# 2048
A simple game where you combine the tiles and the more you combine the higher your score. just make sure you dont get stuck or otherwise its game over.

## FEATURES
- sliding tiles
- combining tiles
- score counter
- game over screen
- nice smooth animations
- clean design

## HOW TO RUN
Just go to the releases page [here](https://github.com/nurali-amirgali/2048-game/releases/tag/V1.0) and download the executable for your os and the open it.
It might flag the app as malicious but thats because its unsigned. just click run anyway. If you dont feel safe you may build from source and since its python it should be very simple. 
Enjoy!
